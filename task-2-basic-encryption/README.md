 Basic Encryption & Decryption (Caesar Cipher)

 Project Overview
This project is a Python implementation of the **Caesar Cipher** encryption algorithm developed for **DecodeLabs Internship (Project 2)**. The goal is to demonstrate data confidentiality concepts and modular arithmetic encryption.

 Features
* Dynamic user input for plaintext and shift keys.
* Full symmetric encryption and decryption flow.
* Preserves letter case (uppercase/lowercase) and retains special characters/spaces.
